# Abstenção presidencial e eleições para governador — 2022

Script em R para comparar a variação da abstenção presidencial entre os turnos com o turno em que se definiu a eleição para governador.

## Arquivos

- `infografico_abstencao_governador_2022.R`: calcula os indicadores e gera o infográfico.

## Dados

O script lê `abstencao_2022.xlsx`, aba `dados`. A planilha não precisa ser publicada junto com o código.
